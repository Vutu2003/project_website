## Version / Conflict Handling

A second client made the browser's plan version stale. PATCH returned 409 `OPTIMISTIC_LOCK_CONFLICT`; the page showed a concurrency-specific message and reload control. After reload, the user could submit a new edit. Other 409 business errors retain their backend message; there is no silent retry or local status override.

## API Contract Audit
